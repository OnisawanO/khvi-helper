2. Non-Functional Requirements (NFR)
ID	Topic	Description
NFR-01	Authorization	ระบบต้องควบคุมสิทธิ์การเข้าถึงตาม Role ได้แก่ User, Interpreter, Manager และ Admin
NFR-02	Personal Data Privacy	ระบบต้องป้องกันข้อมูลส่วนบุคคล เช่น เบอร์โทรศัพท์ อีเมล และข้อมูลยืนยันตัวตน
NFR-03	Contact Privacy	ระบบต้องไม่เปิดเผยข้อมูลติดต่อส่วนตัวของล่ามก่อนถึงสถานะที่กำหนด
NFR-04	Performance	ระบบควรตอบสนองคำขอทั่วไปของผู้ใช้ภายในเวลาที่เหมาะสม เช่น ไม่เกิน 3 วินาทีภายใต้โหลดที่กำหนด
NFR-05	Reliability	ระบบต้องสามารถบันทึกข้อมูลการจอง การรับงาน การเริ่มงาน และการจบงานได้อย่างถูกต้อง
NFR-06	Data Integrity	ระบบต้องป้องกันข้อมูลการจองซ้ำหรือข้อมูลสถานะงานที่ขัดแย้งกัน
NFR-07	Usability	ระบบต้องมี Interface ที่เข้าใจง่ายและเหมาะสำหรับผู้ใช้ที่ไม่สามารถอ่านภาษาไทยได้
NFR-08	Multilingual	ระบบต้องรองรับ Interface หลายภาษา และสามารถเพิ่มภาษาใหม่ได้ในอนาคต
NFR-09	Responsive Design	ระบบต้องสามารถใช้งานได้บน Smartphone, Tablet และ Computer
NFR-10	Compatibility	ระบบควรรองรับ Web Browser ที่ได้รับความนิยม เช่น Chrome, Edge, Safari และ Firefox
NFR-11	Scalability	ระบบต้องสามารถรองรับจำนวนผู้ใช้ ล่าม และการจองที่เพิ่มขึ้นในอนาคต
NFR-12	Maintainability	ระบบต้องมีโครงสร้างที่ง่ายต่อการแก้ไข
NFR-13	Recovery	ระบบต้องสามารถกู้คืนข้อมูลและบริการได้เมื่อเกิดความผิดพลาด
NFR-14	Audit Log	ระบบควรบันทึกกิจกรรมสำคัญ เช่น การ Login การเปลี่ยน Role การอนุมัติล่าม การล็อกบัญชี และการลบบัญชี
NFR-15	Accuracy	ข้อมูลตำแหน่ง สถานะการจอง และข้อมูลล่ามต้องมีความถูกต้องและเป็นปัจจุบัน
