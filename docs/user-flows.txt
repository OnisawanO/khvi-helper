ผังด้านบนคือ เส้นทางหลักฝั่ง User ซึ่งอิงแนวคิดจาก Fastwork ตรงๆ: ค้นหา → ดูโปรไฟล์ → จอง → "ห้องงาน" ที่เป็นศูนย์กลาง (เทียบเท่าหน้าต่างแชท/ออเดอร์ของ Fastwork ที่ยึดหลัก "1 งาน = 1 ห้อง" และใช้ติดตามสถานะทุกอย่างในที่เดียว) → รีวิว/ทิป

ด้านล่างนี้คือแผนหน้าจอของทั้ง 4 role แบบเต็ม พร้อมจุดเชื่อมโยงกัน:

User (ผู้ใช้บริการ)
หน้า	เชื่อมไปยัง
1. ค้นหา/รายชื่อล่าม (หน้าแรกหลัง login)	→ โปรไฟล์ล่าม (คลิกการ์ด)
2. โปรไฟล์ล่าม	→ แบบฟอร์มจอง (ปุ่ม "จองเลย")
3. แบบฟอร์มจอง	→ ห้องงาน & แชท (หลังยืนยัน)
4. ห้องงาน & แชท (ศูนย์กลาง)	→ รีวิว/ทิป (เมื่อสถานะ = จบงาน), → ขอความช่วยเหลือ (ปุ่มลอยตลอดเวลา)
5. รีวิว & ทิป	→ กลับสู่ประวัติการจอง
6. ประวัติการจอง (list ทุกสถานะ)	→ คลิกรายการเก่า กลับเข้าห้องงานเดิม (read-only)
7. ขอความช่วยเหลือ	เข้าถึงได้จากห้องงาน หรือเมนูหลัก
8. สมัครเป็นล่าม (entry point)	→ เข้าสู่ flow ฝั่ง Interpreter
Interpreter (ล่าม)
หน้า	เชื่อมไปยัง
1. ใบสมัครล่าม (กรอกครั้งแรก)	→ หน้าสถานะใบสมัคร
2. สถานะใบสมัคร (Pending/Under Review/Approved/Rejected)	เมื่อ Approved → ปลดล็อกเมนูรับงาน
3. Dashboard ล่าม (รายการงานที่ขอเข้ามา)	→ รายละเอียดงาน (คลิกรายการ)
4. รายละเอียดงาน (รับ/ปฏิเสธ)	เมื่อรับ → ห้องงาน & แชท (หน้าเดียวกับ User ใช้ แต่มุมมองล่าม)
5. ห้องงาน & แชท	→ ปุ่มเริ่ม/จบงาน → ระบบพากลับ Dashboard อัตโนมัติ
6. ตั้งค่าพร้อม/ไม่พร้อมรับงาน	toggle ได้จาก Dashboard โดยตรง (ไม่ต้องเปลี่ยนหน้า)
7. ประวัติงาน/รีวิวที่ได้รับ/ทิปที่ได้รับ	เข้าถึงจากเมนูโปรไฟล์ตัวเอง
8. ขอความช่วยเหลือ	เหมือนฝั่ง User

จุดสำคัญ: หน้า "ห้องงาน & แชท" ควรสร้างเป็น component เดียว ใช้ร่วมกันทั้ง User และ Interpreter เพียงสลับมุมมอง (permission) ตาม role — ลดงานสร้างซ้ำ และตรงกับที่ Fastwork ใช้หน้าต่างแชท/ออเดอร์เดียวกันทั้งสองฝั่ง

Manager (ผู้ประสานงาน)
หน้า	เชื่อมไปยัง
1. Dashboard ผู้ประสานงาน	แสดงสรุป: ใบสมัครรอตรวจ + คำขอช่วยเหลือค้างตอบ
2. รายชื่อผู้สมัครล่าม (list)	→ รายละเอียดผู้สมัคร
3. รายละเอียดผู้สมัคร	ปุ่ม อนุมัติ/ปฏิเสธ(+เหตุผล) → กลับไป list พร้อมอัปเดตสถานะ
4. รายการคำขอความช่วยเหลือ (list)	→ รายละเอียดคำขอ
5. รายละเอียดคำขอ	พิมพ์ตอบกลับ → ปิดคำขอ (status: Answered)
Admin
หน้า	เชื่อมไปยัง
1. Dashboard แอดมิน	สรุปจำนวนบัญชี/งาน/สถิติภาพรวม
2. รายชื่อบัญชีทั้งหมด (ค้นหา/กรองตาม role)	→ รายละเอียดบัญชี
3. รายละเอียดบัญชี	แก้ไขข้อมูล / ล็อก-ปลดล็อก / ลบ / เปลี่ยน Role
4. Ranking & สถิติล่าม	ดู average_rating, completed_job_count ทั้งหมด → block/ban ได้จากหน้านี้
5. Audit Log	log ทุกการกระทำของ admin (อ่านอย่างเดียว)
